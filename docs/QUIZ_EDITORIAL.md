# Викторина: редактура RU/EN, patch 11

Это отчёт о состоянии patch 11. Последующее расширение базы и снятие отдельного
потолка сложности описаны в [QUIZ_EXPANSION.md](QUIZ_EXPANSION.md).

Основа патча: `hangman-2.0(20260911-080523).zip`, без дополнительных промежуточных патчей.
Перенесены утверждённые предложения из разбора от 10 сентября 2026 года:
800 пар, по 80 вопросов каждой темы на каждом языке; 88 пар с правками текста,
28 замен факта, 416 пар только с пересмотром сложности, 268 без правок.
Фактически изменены 522 русские и 527 английских карточек.

При замене факта исходный ID удалён из игровой базы. Новые ID 801–828 выданы
по возрастанию исходного ID. Соответствие сохранено в `retired_ids` редакторского
каталога исключительно для аудита; это не миграция истории между разными фактами.
Исправления текста, ответов и сложности сохраняют прежний ID.

## Подбор и сохранения

Общая адаптация виселицы и викторины по результатам каждого этапа сохраняется.
Временная прибавка сложного уровня, этапы, награды и учёт помощи не менялись.

В patch 11 целевое значение викторины было ограничено 0,68; patch 12 убирает
этот отдельный потолок и использует цель этапа виселицы. Введённый в patch 11 параметр
`difficulty.quiz_pick_window = 0.08` заменяет `question_pick_jitter`.
Сначала формируется окно ±0,08 от цели; затем выбирается случайный ещё не
показанный вопрос внутри окна. После исчерпания локального пула используются
повторы, с исключением последних восьми показов. Если подходящих карточек меньше,
постепенно разрешаются самые давние из этих показов. Ближайший вопрос за пределами
окна используется только при пустом окне; недавняя история не вытесняет подбор
на произвольную далёкую сложность. Уже назначенный этап сохраняет свою карточку.
Предварительный подбор ещё не начавшегося этапа не отмечает вопрос просмотренным.

До расширения patch 12 на сетке целей 0,08–0,68 с шагом 0,01 пустые окна были только:

| Язык | Тема | Цели с выбором ближайшей оценки |
|---|---:|---|
| RU | 6 | 0,67–0,68 |
| EN | 1 | 0,65–0,68 |
| EN | 6 | 0,67–0,68 |

Новые оценки — редакторская оценка для аудитории 25–35 лет, не результат
измерений на игроках. Наличие вопросов в диапазоне само по себе не доказывает,
что именно 60% игроков будут находиться в нём.

Замена вопроса за подсказку использует тот же подбор и исключает текущий ID.
Обычный отдельный режим викторины сохраняет свой случайный выбор по теме.

Каждый новый показ перемешивает копию четырёх ответов и пересчитывает правильный
индекс. Общий кэш базы остаётся неизменным. Сохранение содержит фактический порядок
ответов. Возобновление не перемешивает его повторно и сохраняет 50/50.
При изменении текста или ответов незавершённая карточка обновляется из базы;
уже оплаченные 50/50 и флаг замены сохраняются, скрываются два неверных ответа.
Удалённый факт заменяется обычным подбором для текущего этапа, без переноса
истории на новый факт и без начисления результата за саму миграцию.
Снимки уже завершённых этапов и выдачи наград не переписываются.
При добровольной замене карточки 50/50 сбрасывается, как в исходном проекте;
сброс теперь записывается до первого ожидания анимации, а не после него.

## Редакторский источник и проверки

`data/quiz_catalog.json` содержит текущие RU/EN карточки, причины изменений,
ссылки, даты проверки и заметки для следующих обновлений. Внешняя проверка
зафиксирована для 25 пар; у остальных стоит `editorial_only`. Это не утверждение
о независимой проверке всех фактов по источникам. Старые удалённые карточки
в каталог как резерв не включены.

Каталог исключён из всех текущих экспортных пресетов. `tools/*` и `docs/*`
также исключены. Игра продолжает читать только `quiz_questions_ru/en.json`
с шестью полями карточки; каталог не загружается во время игры.

После редактирования каталога:

```sh
python3 tools/verify_quiz_catalog.py --write
python3 tools/verify_quiz_answer_leaks.py
python3 tools/tests/test_quiz_editorial.py
```

Без `--write` валидатор проверяет совпадение каталога с игровыми JSON,
ID и замены, варианты и правильный индекс, сложность, экспортные фильтры,
числовые подсказки и дословные дубли. Похожие по смыслу вопросы выводятся
кандидатами для редактора; автоматическая проверка не заменяет оценку смысла.
В утверждённом содержимом остаются три EN-кандидата: 228/551 (разные блюда),
297/695 (разные инструменты) и 262/713 (пирамида/пирамиды Гизы — близкий факт
о стране). Они не удалены дополнительно к утверждённым 28 заменам.

Регрессионные фикстуры со старыми примерами доступны только в `tools/tests`.
Они проверяют Windows 98 → 1998, ISBN-13 → thirteen/тринадцать, явные числовые
названия, перефразированные дубли между темами, общие слова и числа во всех
вариантах. Их наличие не добавляет удалённые вопросы обратно в игру.

Godot 4.6.1, с отдельным каталогом пользовательских данных:

```sh
XDG_DATA_HOME=/tmp/hangman-quiz-test godot --headless --path . res://tools/tests/quiz_editorial.tscn
XDG_DATA_HOME=/tmp/hangman-stage-test godot --headless --path . res://tools/tests/stage_difficulty.tscn
XDG_DATA_HOME=/tmp/hangman-rewards-test godot --headless --path . res://tools/tests/rewards.tscn
```

Проверяются ограниченный подбор, повторы, стабильный порядок при восстановлении,
сохранение истории, обе локали, миграция удалённых ID, оплаченные подсказки и
согласованность снимка во время анимации замены. Прогоны викторины и этапов
завершаются предупреждением ObjectDB о живых объектах при закрытии тестовой
сцены; ошибок парсера и ошибок проверок нет. Мобильная сборка на устройстве
этим набором тестов не проверяется.
