У каждого вопроса четыре ответа; правильные позиции сбалансированы:
в легкой части по 10 на каждую позицию, в оставшейся по 5.

Целевая аудитория: 25–40 лет, общее образование, повседневный опыт,
узнаваемые фильмы, музыка, спортивные бренды и популярные факты.
Большинство исторических вопросов не требуют знания точных дат;
годы в вопросах о кино уточняют конкретную экранизацию.
Бытовые и культурные факты составляют основу добавки.

Оценки сложности — редакторские стартовые значения в существующей шкале,
а не измеренная вероятность ошибки. После накопления ответов игроков
нужна калибровка отдельно для RU/EN. Источники точечной проверки
(IAU, NASA, Nutella) добавлены в каталог; остальные новые записи честно
отмечены `editorial_only`.

Количество доступных вопросов ≤0.16 выросло с 246 до 646 в RU
и с 252 до 652 в EN. В самых небольших легких пулах темы «Люди»
теперь 53 RU и 51 EN. При вводном потолке 0.12 доступны
504 RU и 505 EN вопросов суммарно. Эти числа описывают емкость базы,
а не гарантию отсутствия повторов при любой последовательности выбора тем.

## Совместимость с выпущенной версией

Новые ID выделены монотонно: 1329–1928. RU/EN одного факта имеют один ID.
Старые 1300 карточек каждого языка, их порядок, сложности, ключи ответов,
все старые объяснения, редакторские записи и таблица retired_ids неизменны.
Формат сохранений, адаптация, выбор тем и код подбора не изменяются.
Миграция сохранений не нужна: история старых ID продолжает работать,
а новые ID считаются не просмотренными.

Редакторские метаданные находятся только в `quiz_catalog.json`.
В runtime-файлах остаются прежние шесть полей карточки;
объяснения дополняются в существующих отдельных файлах.
База виселицы не меняется.

## Проверка и применение

Добавлен `tools/verify_easy_quiz_expansion.py`: проверяет квоты, ID,
баланс правильных позиций и контрольные суммы всех прежних записей.
Регрессия `easy_quiz_expansion` проверяет загрузку обоих языков,
доступность новых объяснений, портретную верстку, сорок новых легких
фактов перед повтором старых и сохранение истории старых/новых ID.
Дополнительно запускается существующая `quiz_selection_pool`.

```sh
python3 tools/verify_quiz_catalog.py
python3 tools/verify_quiz_answer_leaks.py
python3 tools/verify_easy_quiz_expansion.py
python3 tools/run_content_tests.py --godot godot --suite easy_quiz_expansion
python3 tools/run_content_tests.py --godot godot --suite quiz_selection_pool
```

Перед применением из корня проекта:

```sh
git apply --check /path/to/hangman_20261004_easy_quiz_60_per_theme.patch
git apply /path/to/hangman_20261004_easy_quiz_60_per_theme.patch
```

Патч не затрагивает `export_presets.cfg`.
