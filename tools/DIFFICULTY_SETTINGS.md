# Настройка сложности

Правила хранятся в [game_design_config.json](../data/game_design_config.json). Исходные оценки слов берутся из редакторского каталога. Результаты игрока не меняют оценки и очереди.

## Кроссворды

Для каждого языка и темы сортируем каталог по сложности и постоянному ID. Индексы из `difficulty.word_wave_order` переставляют слова внутри каждой группы. Более лёгкие ответы возвращаются после локальных пиков, а диапазон каждой следующей полной группы выше предыдущей. Дополнительные слова сетки подбираются из ближайшей части оставшейся очереди с учётом пересечений. Каждый десятый уровень увеличивает размер сетки по `progression.bonus_level`.

Показанные ответы, включая дополнительные, исключаются из будущего подбора во всех темах этого языка. Учебные ответы зарезервированы до их уровней. Повтор поражения восстанавливает ту же сетку. Изменения каталога сохраняют ранее показанные ответы в доступной истории.

## Викторины

Цель зависит от номера уровня. `difficulty.default` задаёт начало кривой, `difficulty.maximum` задаёт предел, `difficulty.quiz_levels_to_maximum` определяет, за сколько уровней достигается предел. `difficulty.chain_spread` задаёт разброс целей между вопросами внутри уровня.
