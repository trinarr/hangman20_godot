# Подбор вопросов викторины

Изменения для актуального проекта и отдельно присланного game_design_config.json.

- `difficulty.quiz_pick_window` сохраняет обычное окно вокруг сложности этапа.
- `difficulty.quiz_min_pool_size` (по умолчанию 12) задаёт желаемый минимум кандидатов.
- Если в окне меньше кандидатов, добавляются ближайшие более лёгкие вопросы текущей темы. Вопросы одинаковой сложности на границе добавляются все, поэтому итоговый набор может быть больше минимума.
- Верхняя граница остаётся `target + quiz_pick_window`. Если безопасных вопросов меньше 12, используются доступные. Если их нет совсем, селектор возвращает пустой результат.
- Внутри набора приоритет имеют непоказанные вопросы. После их исчерпания используются вопросы вне последних восьми показов, а если таких нет — наиболее давно показанный из сохранённой истории.
- Последний показанный вопрос исключается при наличии альтернатив даже при неполной истории `seen`. Подсказка замены всегда исключает текущий вопрос.
- История уже хранится отдельно для языка и темы. Новых полей сейва не требуется; восстановление сохранённого вопроса и порядка ответов не меняется.
- Изменение применяется к выбору нового вопроса кампании и общей функции замены вопроса. Уже сохранённый вопрос уровня не пересоздаётся. Отдельный режим викторины не получает новую историю кампании.
- Формулы глобальной/вводной сложности, награды и подбор слов не меняются. Квота пропущенного контента 20–25% не добавлена.

## Проверка

Запускать с отдельным XDG_DATA_HOME, чтобы автозагрузки не использовали игровые сохранения:

```sh
XDG_DATA_HOME="$(mktemp -d)" godot --headless --path . --script res://tools/tests/quiz_selection_pool.gd
```

На Godot 4.6.1: 2115 проверок, 0 ошибок. Проверены оба языка, все темы, приоритет непоказанных, повтор после исчерпания, ограничение сложности, замена, равные оценки, отсутствие изменения входных данных.
На сложности 0.86 за 40 выборов на тему получено суммарно 140 разных вопросов RU и 147 EN без немедленных повторов. Это проверка поведения селектора, не прогноз охвата всей кампании.

Существующий интеграционный тест `quiz_expansion.tscn` проверен дополнительно, но не прошёл: фикстура возобновления сессии сообщает `Resumed quiz screen capped the target: ru`, затем обращается к отсутствующему `data`. Такое же поведение воспроизводится с исходным, неизменённым селектором при текущих исходниках/настройках. Полный сценарий восстановления сессии этим запуском не подтверждён. В тесте обновлена только фикстура проверки целевой сложности под расширенный набор кандидатов.
