# Пояснения к ответам викторины

Добавлены 1100 пояснений на русском и 1100 на английском: по 110 на тему.
Они привязаны к стабильному `id` вопроса, поэтому перестановка вариантов ответа
не влияет на выбор текста. Вопросы, ответы и сложности не изменены.

## Данные и показ

- `data/quiz_explanations_ru.json` и `data/quiz_explanations_en.json` содержат
  `format_version`, `language` и словарь `explanations`: строковый ID → пояснение.
- `Database.get_quiz_answer_explanation(question_id)` использует язык базы слов
  и викторины, независимо от языка интерфейса. Файл загружается при первом
  обращении; последующие показы используют неизменяемый кэш.
- Пояснение заменяет вопрос при появлении «Продолжить»: после обратной связи
  об ответе и, если заработаны звёзды за скорость, после их сбора в счётчик.
  Это работает при правильном и неправильном ответе, в отдельной викторине
  и на этапе одиночной игры. Порядок начисления наград не меняется.
- При восстановлении уже отвеченного экрана пояснение показывается сразу.
  Повторного начисления наград нет. Следующий вопрос возвращает обычный текст.
- Если пояснение отсутствует, остаётся текст вопроса; продолжение доступно.

Каждый текст занимает одно-два коротких предложения. Используются текущие
шрифт, размер и область вопроса. В готовый экспорт входят оба JSON; тесты
и этот документ исключаются существующим правилом `tools/*`.

При добавлении вопроса добавьте его ID в оба файла. При удалении — удалите
соответствующие пояснения. При изменении факта или ответа проверьте пояснения
обоих языков. Отдельного редакторского генератора для этих файлов нет.

## Проверка

Godot 4.6.1, из корня проекта:

```bash
XDG_DATA_HOME=/tmp/hangman-quiz-explanations-test godot --headless --path . res://tools/tests/quiz_explanations.tscn
```

Используйте отдельный пустой каталог для `XDG_DATA_HOME`: интеграционные тесты
меняют сохранённый прогресс. Тест проверяет полноту ID, язык, отложенную загрузку,
вместимость каждого текста, оба результата ответа, три категории скорости,
завершение анимации награды, восстановление результата и следующий вопрос.

Проверка экспорта ресурсов:

```bash
godot --headless --path . --export-pack "Hangman 2.0" /tmp/hangman-explanations.pck
```

В пакет должны входить оба `data/quiz_explanations_*.json`.
