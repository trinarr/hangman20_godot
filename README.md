# Hangman 2.0 / Виселица 2.0

Игра на Godot для **Android** с русским и английским интерфейсом и игровым контентом. Текущая среда разработки — Windows. Настольные тесты проверяют логику; работу на Android проверяют отдельной сборкой и запуском на устройстве.

## Среда и первый запуск

- `project.godot` объявляет Godot **4.7**, renderer **Mobile**. Последний локальный прогон выполнен на **4.7.2 stable**; другие версии отдельно не проверялись. Для воспроизводимости используйте эту версию редактора и соответствующие ей export templates. Android-сборка на ней пока не подтверждена.
- Импортируйте `project.godot` в Godot, дождитесь импорта ресурсов и запустите проект через F5. Главная сцена — `scenes/Main.tscn`.
- Для инструментов используйте Python 3.10+; последний прогон выполнен на Python 3.12. Валидаторы контента используют стандартную библиотеку. Для проверки манифеста графики нужны `Pillow` и `numpy`; при отсутствии установите их в локальное виртуальное окружение.
- Android SDK, JDK, Gradle-шаблон и подпись нужны для [сборки Android](tools/EXPORT.md). Для контентных Python-проверок Android toolchain не требуется.

Минимальная проверка из корня проекта:

```powershell
python tools/verify_game_design_config.py
python tools/verify_optimization.py
python tools/curate_word_database.py --check
```

Полные команды и изоляция сохранений описаны в [tools/TESTS.md](tools/TESTS.md). Для тестов на Windows Linux не требуется. Обычный запуск игры использует профиль игрока; регрессии запускайте через изолированные тестовые инструменты.

## Источники актуальных значений

- Баланс, цены, награды и таймеры: `data/game_design_config.json`; доступ из кода — `scripts/core/game_design_config.gd`.
- Слова/подсказки: редакторские `data/word_catalog_*.json`; `tools/curate_word_database.py --check` проверяет runtime-экспорт, запуск без `--check` записывает его.
- Викторина: `data/quiz_catalog.json`; `tools/verify_quiz_catalog.py` проверяет runtime, `--write` пересоздаёт его.
- Переводы UI: `localization/translations.csv`; палитра и шрифты: `scripts/ui/ui_palette.gd`, `scripts/ui/ui_fonts.gd`.
- Приложение и autoload: `project.godot`; Android-пресет: `export_presets.cfg`; список тестовых сценариев: `--help` соответствующего запускателя.

В текущих инструкциях не дублируются таблицы баланса и размеры каталога. Числа в отчётах — результаты проверки конкретного состояния, а не действующая спецификация.

## Поддержка документации

В рабочем дереве хранятся актуальные инструкции, контракты и открытые проблемы. Старые патч-отчёты и закрытые пункты доступны через Git: `git log -- <путь>` для истории файла, `git show <commit>:<путь>` для его прежнего содержимого. Повторно накладывать старые патчи для настройки checkout не требуется.

Меняя процессы запуска и сборки, обновляйте соответствующую инструкцию. Причины архитектурных ограничений фиксируйте в [ARCHITECTURE.md](docs/ARCHITECTURE.md); не добавляйте отдельный отчёт на каждый патч. Проверенную версию движка указывайте здесь, известные сбои — в аудите. Успешные настольные тесты не подтверждают сборку APK, работу рекламы и внешний вид на телефоне.
