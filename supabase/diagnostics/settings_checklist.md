# Дополнение к SQL-отчётам

Заполнять локальную копию вне Git. Значения секретов, ключей, паролей и пользовательские записи не прикладывать. Если параметр не найден или недоступен, писать «не проверено», а не «выключено».

| Область | Что зафиксировать | Результат |
| --- | --- | --- |
| Проект | Название/ref проекта, дата и время UTC, регион, версия PostgreSQL | |
| Исполнение SQL | Использованная роль, какие файлы завершились успешно, ошибки/timeout | |
| Data API | Включён ли API; точный список Exposed schemas и дополнительных search paths | |
| Auth | Включены ли Anonymous Sign-In и регистрация; разрешённые провайдеры | |
| Auth | Настройки срока JWT, refresh token rotation, повторного использования токенов; только параметры, не сами токены | |
| Защита регистрации | Rate limits, CAPTCHA, фактическая совместимость с Anonymous Sign-In игры | |
| Ключи | Какие типы ключей используются клиентом/сервером, назначение и где хранятся; без значений | |
| Доступ команды | Роли участников и наличие MFA; без списка личных email | |
| Сеть | SSL enforcement, ограничения подключения к Postgres/pooler | |
| Edge Functions | Используются ли; имена/версии, проверка JWT, список имён секретов без значений | |
| Storage | Используется ли; публичность бакетов, политики и ограничения загрузок | |
| Realtime | Используется ли; включённые публикации/таблицы и предполагаемый доступ | |
| Резервные копии | Наличие, период хранения, PITR, дата последней проверки восстановления в отдельной среде | |
| Нагрузка | Тариф/compute, квоты и использование БД, соединений, Storage и трафика | |
| Security Advisor | Дата запуска, WARN/ERROR с названием проверки и объекта | |
| Performance Advisor | Дата запуска, WARN/ERROR с названием проверки и объекта | |
| Журналы | Интервал UTC, источник, маршрут, число 4xx/5xx, коды ошибок; без заголовков авторизации и тел запросов | |

Отсутствие Storage/Realtime/Edge Functions тоже зафиксировать после проверки. Для резервирования Storage отдельно проверить наличие копии самих файлов: резервная копия БД содержит их метаданные, а не содержимое объектов.
